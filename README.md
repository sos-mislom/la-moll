# Ла-Молл

Статический лендинг с видео-фоном и короткой формой регистрации.

## Заявки В Telegram

Форма отправляет POST на `/api/register`. Для автоотправки в Telegram задеплойте проект на Vercel и задайте переменные окружения:

- `BOT_TOKEN` - токен Telegram-бота.
- `TELEGRAM_CHAT_ID` - чат или канал, куда слать заявки.

Если endpoint недоступен, сайт не ломается: текст заявки копируется в буфер, а пользователь получает ссылку на Telegram организаторов.

## Локально

Открыть `index.html` в браузере достаточно для просмотра. Автоотправка формы работает только при наличии serverless endpoint.
